## 第 2 张：API Key = 不记名免密副卡，守住 4 条铁律

**页眉标签**：01｜守住密钥

1. **绝不写死在代码里**：真钥匙放本地 `.env` 并加进 `.gitignore`，仓库里只交空模板 `.env.example`。
2. **先设硬消费上限**：新 Key 立刻设预算上限（如 `20 美元`），锁死极端风险。
3. **泄露第一动作是「吊销」**：误推 GitHub 后只删文件没用（Git 历史里还在！），必须**立刻去后台吊销重签**。
4. **认识 GitHub Push protection**：推错密钥时会自动拦截，但它是安全气囊，绝不能替你系安全带。

## 第 3 张：职场数据「红黄绿三灯清单」

**页眉标签**：02｜什么能喂 AI

- **🟢 绿灯（直接用）**：公开数据快照、公开研报、自己编的脱敏测试表。
- **🟡 黄灯（隔离 + 关日志后用）**：内部运营汇总、无隐私 SKU 销量表。
- **🔴 红灯（绝不裸奔喂公有云）**：客户身份证/手机号、员工工资条、银行账户、未公开财报、保密协议合同、密码和 `.env`。

---

## 第 4 张：别忘了关掉工具里的「上传会话日志」开关

**页眉标签**：03｜检查隐私开关

实测 DeepSeek Harness 默认把 **「在使用官方模型 API 时上传 Session Log」** 设为开启状态！

只要开始处理任何黄灯内部业务资料，第一步进「设置 → 通用设置」拉到最底把它关掉；用 Codex、豆包等其他工具时也同样先查隐私设置。

---

## 第 5 张：高光绝招——「本地脚本先脱敏，原表不出电脑」

**页眉标签**：04｜既提效又安全

手里有 3,000 行真实客户表想让 AI 帮做分析？照这 3 步做：

1. 只把**表头 + 2 行编造的假样例**发给 AI；
2. 让 AI 写出本地脱敏脚本 `anonymize.py` 和统计脚本；
3. 自己在终端本地运行——3,000 个客户手机号**一个字节都不离开你的电脑**！

很多职场人想用 AI 编程工具帮自己干活，又最担心两件事：API Key 泄露被人一分钟刷爆额度，或者把公司敏感表格喂进云端出大事故。

- 职场数据「红黄绿三灯清单」；
- 容易漏关的「上传 Session Log」默认开关；
- 怎么用「只给表头+假样例 → 本地跑脚本」做到真实隐私零上传！
