## 第 2 张：为什么 AI 一开口全是斜杠？

**页眉标签**：01｜路径就是门牌号

你找文件靠眼睛和鼠标双击；AI 没有鼠标，它找文件全靠一行文字地址——这就是**路径（Path）**。

同一张销售表，在两个系统里长这样：

- **Windows**：`C:\Users\xiaolin\青禾文具\sales\2026-10-销售明细.xlsx`（盘符开头，反斜杠 `\`）
- **Mac / Linux**：`/Users/xiaolin/青禾文具/sales/2026-10-销售明细.xlsx`（斜杠 `/` 开头，正斜杠 `/`）

从头写完叫**绝对路径**；如果已经站在 `青禾文具` 文件夹里，直接写 `sales/2026-10-销售明细.xlsx` 就叫**相对路径**。

## 第 3 张：必认的 3 个特殊符号（防 AI 越界）

**页眉标签**：02｜符号解码

在 AI 的命令或弹窗里看到这 3 个符号，一定要一眼认出来：

- **`.`（一个点）**：当前所在的文件夹。
- **`..`（两个点）**：往外退一层（上一级文件夹）。看到 `../` 要立刻警觉——AI 正在往当前工作区外面伸手。
- **`~`（波浪号）**：当前登录用户的主目录（Mac 是 `/Users/你的用户名`，Windows PowerShell 对应 `C:\Users\你的用户名`）。

小提醒：给工作文件夹起名尽量别带空格，用 `-` 或 `_` 代替，能省掉一半命令报错。

## 第 4 张：常见扩展名（文件后面的「身份证」）

**页眉标签**：03｜看后缀认文件

文件名最后一个点后面的字母叫**扩展名**，常见这 6 种先混个眼熟：

- **`.xlsx` / `.csv`**：Excel 表格 / 纯文本逗号表
- **`.py`**：Python 脚本（AI 替你干活写出来的程序）
- **`.md`**：Markdown 纯文本文档（`README.md`、`AGENTS.md` 都是它）
- **`.json` / `.yaml`**：配置文件（AI 工具和程序用来存设置）

别踩误区：**直接把 `.xlsx` 改名成 `.csv` 不会转换格式**，只是换了盒子外面的贴纸，程序照样打不开。

## 第 5 张：千万别乱动的 3 个隐藏文件

**页眉标签**：04｜隐藏文件

以点 `.` 开头的文件默认会藏起来（Mac 按 `Cmd + Shift + .` 显示，Windows 在资源管理器勾选「隐藏的项目」）：

1. **`.env`**：存 API Key 和密码的保险箱——**绝不能发给别人或上传到公开仓库**。
2. **`.git`**：Git 存档库文件夹——**千万别手痒删掉**，删了历史记录全没。
3. **`.gitignore`**：告诉 Git 哪些文件不上传的「黑名单」（里面通常第一行就写着 `.env`）。
