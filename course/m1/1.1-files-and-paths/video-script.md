# 1.1 录播参考脚本：文件、文件夹和「路径」

> 建议时长：8–10 分钟（边看文件夹和终端对照边讲，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Path | 帕斯（或直接说「路径」） | 文件在你电脑里的完整门牌地址 |
| File Extension | 中文直接说「扩展名」或「后缀」 | 文件名最后一个点后面的字母，告诉系统用什么软件打开 |
| `.xlsx` / `.csv` | 点 X-L-S-X / 点 C-S-V | Excel 表格 / 纯文本逗号分隔表格 |
| `.py` | 点 P-Y | Python 脚本文件 |
| `.env` | 点 E-N-V（environment 的缩写） | 存放 API Key 和密码的隐藏配置文件 |
| `.git` | 点 git | Git 用来保存历史存档的隐藏文件夹 |
| `.gitignore` | 点 git-ignore | 告诉 Git 哪些文件绝不上传的清单 |
| `~` | 波浪号（或读「家目录」） | 当前登录用户的主文件夹缩写 |
| `..` | 点点（上一级目录） | 往外退一层文件夹 |

## 0:00 – 0:50｜开场 Hook（从一句真实报错切入）

- **屏幕画面**：大字打出一条新手最常见报错：`FileNotFoundError: No such file or directory: 'sales/2026-10-销售明细.xlsx'`，旁边对照展示 `../.env`。
- **口播要点**：
  - 直接切痛点：「以后让 AI 干活，最常见的报错就这一句：找不到文件；最容易吓一跳的审批提示，就是它突然要改一个叫 `../.env` 的东西。」
  - 引出目标：AI 没有手指，没法像你一样用鼠标双击文件夹——**路径就是 AI 定位文件的唯一门牌号**。这节课 10 分钟带你认全 Windows 和 Mac 两种路径、扩展名和 3 个必认的隐藏文件。

## 0:50 – 2:30｜系统位置 + 绝对路径 vs 相对路径

- **屏幕画面**：画出「青禾文具」文件夹树状图（`青禾文具/` 下面有 `sales/`、`output/`、`.env`、`.gitignore`），左右并列展示同一张表在 Windows 和 Mac 下的写法：
  - Windows：`C:\Users\xiaolin\青禾文具\sales\2026-10-销售明细.xlsx`
  - Mac：`/Users/xiaolin/青禾文具/sales/2026-10-销售明细.xlsx`
- **口播要点**：
  - 用「省 / 市 / 区 / 门牌号」类比绝对路径（从盘符或 `/` 出发，在哪都能唯一找到）和相对路径（假设你已经站在「青禾文具」门口，只要说 `sales/2026-10-销售明细.xlsx`）。
  - **重点点明斜杠差异**：Windows 传统用反斜杠 `\`，Mac/Linux 用正斜杠 `/`；好消息是现在多数 AI 工具和 PowerShell 对 `/` 也能认，但你得两眼都能看懂。

## 2:30 – 4:30｜必认的 3 个特殊符号：`.`、`..`、`~`

- **屏幕画面**：在树状图上用箭头现场标出 `.`（原地）、`..`（往外退一层，直接走出「青禾文具」）、`~`（直接跳回用户主目录）。
- **口播要点**：
  - **特别放慢语速讲 `..`**：给后面 1.3 危险命令埋钩子——只要在 AI 的命令里看到 `..`、`~` 或 `C:\`，立刻警觉，说明它正在往当前工作区外面伸手。
  - 顺带提一句空格坑：文件名带空格在终端里容易截断（比如 `青禾 文具` 会被当成两个词），所以给文件夹起名尽量用连字符 `-` 或下划线 `_`，真有空格就用双引号包起来。

## 4:30 – 6:30｜扩展名和 3 个必须认识的隐藏文件

- **屏幕画面**：切到文件管理器（Mac 现场按 `Cmd + Shift + .` 让 `.env`、`.git`、`.gitignore` 瞬间显形；Windows 展示「查看 → 显示 → 文件扩展名 / 隐藏的项目」）。
- **口播要点**：
  - 快速认一圈高频扩展名：`.xlsx`（Excel）、`.csv`（纯文本表）、`.py`（Python 脚本）、`.md`（说明书文档）、`.json`/`.yaml`（配置文件）。
  - **顺手破误解**：「把 `.xlsx` 后缀改成 `.csv` 是不是就转成 CSV 了？」——绝对不是，就像把牛奶盒上的标签撕了贴上矿泉水标签，里面还是牛奶，程序照样打不开。
  - 逐个点名 3 个隐藏文件：`.env`（装钥匙的保险箱，绝不能发人）、`.git`（游戏存档库，别手痒删掉）、`.gitignore`（不上传清单）。

## 6:30 – 8:30｜现场读 5 条路径 + 下集预告

- **屏幕画面**：屏幕列出 5 条路径（含 `C:\Users\xiaolin\Desktop\报价.xlsx`、`~/青禾文具/output/季度汇总.xlsx`、`../客户名单.xlsx`、`.env`），带着观众逐条口头解码。
- **口播要点**：
  - 落地动作：回去把电脑的「显示文件扩展名」打开（Windows 尤其重要），免得以后把 `合同.xlsx.exe` 当成普通表格。
  - 预告 1.2：认清门牌号后，下一课带你打开那个黑色窗口——**1.2《终端与常用命令》**，把 `cd`、`ls`、`npm`、`npx`、`python`、`pip` 这些以后天天见的命令一次认全。

## 录制注意事项

- 展示本机 Finder 或 Windows 资源管理器时，新建一个独立的「青禾文具」演示目录，避免屏幕左侧栏或地址栏露出个人真实姓名、公司真实目录名或私人文件。
- 演示 `.env` 文件时，里面只写明显虚构的占位字样（例如 `GEMINI_API_KEY=your_key_here`），绝不展示任何真实 API Key。
