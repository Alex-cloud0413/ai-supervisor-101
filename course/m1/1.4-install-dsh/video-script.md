# 1.4 录播参考脚本：装好 DeepSeek Harness

> 建议时长：10–12 分钟（边在终端启动并配置网页版边讲，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Node.js | 诺德 J-S | 运行 DeepSeek Harness 所需的底层环境，去官网点安装包就行 |
| `npx` | N-P-X | Node.js 自带的启动器，一行命令直接拉起工具 |
| Localhost / `127.0.0.1:3080` | 本地地址 3080 端口 | 网页跑在你自己电脑上，不是公网服务器 |
| API Key | A-P-I 钥匙（密钥） | 调用大模型服务的个人通行证，相当于带余额的门禁卡 |
| Provider | 普若外德（中文界面说「提供商」） | 给你提供模型服务的厂商，例如 Google（Gemini）或 DeepSeek |
| Token | 托肯（口播时顺手区分网页链接里的 `?token=` 临时登录口令） | 启动地址末尾带的一次性本地验证口令 |

---

## 0:00 – 0:50｜开场 Hook（先说明两条路线：网页版为主 + 桌面端可选）

- **屏幕画面**：一边展示终端里只敲一行 `npx @deepseek-ai/dsh@0.2.2-rc.5 web`，另一边浏览器瞬间打开 DeepSeek Harness 中文界面。
- **口播要点**：
  - 衔接前 3 课：「前面 3 课把路径、常用命令和危险命令都摸熟了，今天终于动手装工具。」
  - 说明路线：本课主线用 **网页版（`npx` 启动）**，因为 Mac 和 Windows 步骤几乎一模一样，出了报错在终端里一目了然；如果你更喜欢点图标安装，官网（`deepseek.com/harness`）也提供桌面端，和网页版共用同一份 `~/.dsh` 配置和会话记录。

## 0:50 – 2:30｜第一步：装好 Node.js 并验证

- **屏幕画面**：打开 `https://nodejs.org`，指一下下载按钮；切到终端敲 `node -v` 和 `npx --version`。
- **口播要点**：
  - 装 Node.js 就像装微信一样一路点「下一步」，装完记得**关掉旧终端、新开一个终端窗口**再测。
  - **关键提醒**：0.2.2-rc.5 官方要求较新版本（声明 `Node >= 24.9.0`）；如果旧电脑装的是 Node 22，终端可能会刷出一行黄色 `npm warn EBADENGINE`，只要后面能正常打印网址，就不是报错，不用慌。

## 2:30 – 4:15｜第二步：一行命令启动网页版

- **屏幕画面**：终端敲 `npx @deepseek-ai/dsh@0.2.2-rc.5 web`（说明不加版本号默认拉最新版，加版本号和课程画面一致），指着终端打印出的 `dsh web: http://127.0.0.1:3080/?token=...`，切到浏览器看到「预览版说明」弹窗点「继续」，接着看到「开始使用」弹窗。
- **口播要点**：
  - **重点破误解**：很多人看到浏览器打开了，顺手就把黑框终端关掉，结果网页立刻断线。强调：**那个终端窗口是本地发动机，用的时候最小化放着就行；彻底不用了按 `Ctrl + C` 才关掉。**
  - 顺口提醒地址栏里的 `127.0.0.1:3080`：这是你电脑本机地址，文件都在你硬盘上，没上传成公开网站。

## 4:15 – 7:15｜第三步：配好模型 Key（主线 Gemini + 国内 DeepSeek 替代）

- **屏幕画面 1（主线 Gemini）**：
  1. 在「开始使用」弹窗点「添加 API Key」→ 先点「稍后配置」（因为这里默认弹的是 DeepSeek 快捷框）；
  2. 点左下角「更多 → 设置 → 模型」；
  3. 点「添加模型提供商」→ 默认停在「第三方模型提供商」→ 在「提供商」下拉框选 **`google`**（放大圈一下，提醒不是叫 `gemini`）；
  4. 粘贴从 Google AI Studio（`aistudio.google.com/apikey`）申请的 Key，点「保存」。
- **屏幕画面 2（国内学员替代方案：DeepSeek 官方 Key）**：
  - 口播＋画面停在「模型」页顶部第一张 **`DeepSeek`**（`deepseek-official`）卡片：如果国内网络连不上 Google，直接去 `platform.deepseek.com` 充 10 块钱拿一个 API Key，粘进第一张 DeepSeek 卡片点「保存」就行（或者刚打开时的「添加一个 API Key 开始使用」弹窗直接粘进去点「保存并继续」），**不用重启，立刻生效**。
- **口播要点**：
  - 强调安全：DSH 保存密钥后会自动脱敏并存到 `~/.dsh/.credentials.yaml`，页面上再也不会回显明文；但你复制密钥的那张网页不要截图发群里。

## 7:15 – 8:30｜第四步：顺手打开监工必备开关「显示代码工作视图」

- **屏幕画面**：在「设置」里点回「通用设置」，找到并打开 **「显示代码工作视图」**（指着下面那句说明：`开启后，显示轨迹、本轮代码差异，可选择完整的 Agent 预设切换`）。
- **口播要点**：
  - 呼应 0.1 课：不开这个开关，界面默认隐藏「轨迹」和「代码差异」；咱们当监工的，装完第一步就把它打开。

## 8:30 – 10:30｜第五步：选工作区 + 跑通第一个只读盘点任务

- **屏幕画面**：关掉设置，点输入框上方「选择工作区」，选中准备好的 `青禾文具` 文件夹，切左下角到「仅可查看」，发第一条只读任务（盘点 `sales/` 里的 3 张表名、列名和行数）。
- **口播要点**：
  - 盯着结果验证：3 张表分别是 8 月 24 笔、9 月 27 笔、10 月 31 笔，而且立刻能看到 10 月表头叫「销售额」而不是「金额」——这说明工具、模型、工作区整条链路全部打通！
  - 预告 1.5：工具装好了，下节课 **1.5《工作区与权限：给 AI 划好边界》**，专门讲怎么挑工作区、三档权限怎么切、以及沙箱防不住的 2 个真相。

## 录制注意事项

- 粘贴 API Key 时先暂停录屏或使用马赛克遮挡剪贴板/输入框，绝不在视频里露出任何真实明文 Key（DSH 保存后的脱敏显示仍建议核对）。
- 终端打印出的 `http://127.0.0.1:3080/?token=...` 虽只在本机有效，录播结束后请关闭该进程；下次启动会重新生成新 token。
