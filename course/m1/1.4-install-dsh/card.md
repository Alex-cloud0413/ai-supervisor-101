## 第 2 张：准备工作：只需装 1 个底层环境 + 敲 1 行命令

**页眉标签**：01｜启动网页版

1. 去官网 `nodejs.org` 下载安装 **Node.js**（装完重新打开终端，敲 `node -v` 出现版本号即成功）。
2. 在终端输入下面这行并回车：
   `npx @deepseek-ai/dsh@0.2.2-rc.5 web`
3. 终端会打印一个本地地址 `http://127.0.0.1:3080/?token=...` 并自动弹开浏览器。

**避坑提醒**：那个跑着命令的终端黑框是「本地发动机」，用的时候最小化放着就行——**别随手关掉**，关了网页就会断线；真要退出按 `Ctrl + C`。

## 第 3 张：接上模型 Key（Gemini 主线 + DeepSeek 国内替代）

**页眉标签**：02｜配置模型

首次打开点掉「预览版说明」后，按你的网络情况二选一：

- **接 Gemini（课程主线）**：在弹窗点「稍后配置」→ 左下角「更多 → 设置 → 模型」→ 点「添加模型提供商」→ 「第三方模型提供商」里选 **`google`**（注意不是 `gemini`）→ 填入从 `aistudio.google.com/apikey` 申请的 Key → 点「保存」。
- **国内用户接 DeepSeek（最省事）**：去 `platform.deepseek.com` 充少量余额拿 API Key → 直接填进「设置 → 模型」第一张 **DeepSeek** 卡片点「保存」，**不用重启立刻生效**。

## 第 4 张：装完必开 1 个监工开关

**页眉标签**：03｜打开轨迹和 Diff

点进「设置 → 通用设置」，往下翻找到这一项打开：

**「显示代码工作视图」**
（开启后，才能在对话顶部看到「轨迹」流水账和右侧的「本轮代码差异」）

接着关闭设置，点输入框上方的 **「选择工作区」**，选定你专门新建的练习文件夹（比如 `ai-radar`），左下角先选 **「仅可查看」**。

## 第 5 张：跑通第一个安全小任务 + 4 个常见报错速查

**页眉标签**：04｜首测与排错

先发一句只读指令试跑：「盘点 `data/openrouter-models-2026-11-24.json` 一共有多少个模型、前 5 厂商是谁，以及价格 `<= 0` 和带 `:batch` 的各有多少个，不要改任何文件。」能准确报出数字就算全线贯通。

装工具最常见的 4 个提示：

- **`command not found: npx`**：Node.js 没装好，或装完没重开终端窗口。
- **`npm warn EBADENGINE`**：Node 版本略低触发的黄色提醒，只要下面能打印出网址就不是报错。
- **输入框灰掉写「选择一个工作区开始」**：还没选工作区文件夹，点上方「选择工作区」。
- **`MISSING_CREDENTIAL`**：还没填或没保存当前所选模型的 API Key。
