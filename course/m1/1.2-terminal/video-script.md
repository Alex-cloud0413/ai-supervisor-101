# 1.2 录播参考脚本：终端与常用命令

> 建议时长：9–11 分钟（边敲真实终端边讲，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Terminal | 特米诺（中文说「终端」） | 用打字命令控制电脑的窗口 |
| PowerShell | 帕沃谢尔 | Windows 自带的新版终端 |
| CLI | C-L-I（Command Line Interface） | 命令行界面，和鼠标点图标（GUI）相对 |
| `pwd` | P-W-D（Print Working Directory） | 打印你当前正站在哪个文件夹里 |
| `ls` / `dir` | L-S / D-I-R | 列出当前文件夹里的文件 |
| `cd` | C-D（Change Directory） | 切换到另一个文件夹 |
| `mkdir` | M-K-dir（Make Directory） | 新建文件夹 |
| `cat` | 凯特（cat） | 直接把文本文件的内容打印到屏幕上 |
| `python` / `python3` | 派森 / 派森三 | 启动 Python 来运行 `.py` 脚本 |
| `pip` | 皮普（pip） | Python 的应用商店，用来安装表格、PDF 等扩展包 |
| `node` | 诺德（Node） | Node.js 运行环境，DSH 这类网页/桌面工具靠它跑 |
| `npm` | N-P-M | Node.js 的应用商店，用来装包和管理依赖 |
| `npx` | N-P-X | Node.js 的「即拿即跑」启动器，不用提前全局安装就能直接运行工具 |

## 0:00 – 0:50｜开场 Hook（先打消对黑窗口的恐惧）

- **屏幕画面**：同时打开左右两半屏——左边是日常的文件夹窗口，右边是黑底白字的终端，在右边敲一条 `mkdir output`，左边瞬间多出一个 `output` 文件夹。
- **口播要点**：
  - 直接破除畏惧：「很多人一看到黑色窗口闪光标就头皮发麻，觉得那是程序员的专属黑盒，敲错一个字母电脑就会炸。其实它跟桌面文件夹管的是同一块硬盘——左边用鼠标点，右边用打字说。」
  - 说明为什么要学：第一，AI 没有手点鼠标，它干活全靠终端，看懂常用命令才能看懂它在干嘛；第二，到 1.4 课装 DeepSeek Harness 时，你自己就要敲 `node -v` 和 `npx @deepseek-ai/dsh web`。

## 0:50 – 2:00｜怎么打开终端 + 拆解一条命令的 4 段结构

- **屏幕画面**：标注 Mac（`Cmd + Space` 搜「终端」）和 Windows（开始菜单搜「终端」或「PowerShell」）；放大一行命令：`ls -la data`，分别圈出「提示符 / 动词 / 参数 / 目标路径」。
- **口播要点**：
  - 记住固定规律：**第一个词永远是动词（干什么），带 `-` 的是开关参数（怎么干），最后是路径（动哪儿）**。

## 2:00 – 5:00｜第一组：看文件、走目录的 7 个基础命令（现场敲一遍）

- **屏幕画面**：在 `ai-radar` 目录里依次敲：
  1. `pwd`（看自己在哪）
  2. `ls` 与 `ls -la`（看清隐藏文件 `.env`、`.git`、`.gitignore`）
  3. `cd data` → `pwd` → `ls` → `cd ..`（**重点慢讲 `cd`**）
  4. `mkdir output`（新建输出目录）
  5. `cat .gitignore`（快速看纯文本）
  6. `cp` / `mv`（口头演示复制与重命名）
  7. `clear`（把屏幕滚干净）
- **口播要点**：
  - **关键停顿讲 `cd`**：敲完 `cd data` 回车，界面不会弹出任何新窗口，只会默默改变前面那段当前路径提示符——很多新手以为「没反应、失败了」，其实你已经走进去了，不放心就敲一次 `pwd`。
  - **顺手破误解**：敲 `clear` 只是清屏幕显示，绝不会删除文件；Windows 推荐统一用 PowerShell，上面 7 条命令它几乎全能直接认。

## 5:00 – 8:00｜第二组：装工具、跑脚本必见的 5 个命令（`python` / `pip` / `node` / `npm` / `npx`）

- **屏幕画面**：分成左右两列卡片——左边 **Python 阵营（`python3` + `pip`）**，右边 **Node.js 阵营（`node` + `npm` + `npx`）**，终端里依次敲 `python3 --version`、`pip --version`、`node -v`、`npm -v`、`npx --version`。
- **口播要点**：
  - 用「手机系统 + 应用商店」打比方：
    - `python3` 是干活的引擎（跑 `.py` 比价与情报脚本），`pip` 是它的应用商店（`pip install openpyxl` 装导出 Excel 的包）；
    - `node` 是另一套常见引擎（DeepSeek Harness 就靠它跑），`npm` 是它的应用商店；
    - **`npx` 单独点透**：它像「免安装快应用」——不用先永久安装一大堆东西，敲一行 `npx @deepseek-ai/dsh web` 就能把工具拉起来直接跑，这就是 1.4 课要用的那一行。
  - **顺手提醒报错识别**：终端刷出一片 `npm warn` 只是提醒，程序照常跑；真正停住看 `Error` 或 `command not found`。

## 8:00 – 9:30｜读 5 行真实记录 + 下集预告

- **屏幕画面**：展示一段 5 行终端流水账（`cd` → `ls` → `pip install openpyxl` → `python3 build_top10.py` → `npx @deepseek-ai/dsh web`），带着观众逐行口头翻译。
- **口播要点**：
  - 总结：你不需要背下来自己手敲，只要做到「看到 AI 或教程弹出这 12 个词，一眼知道它在干嘛」。
  - 预告 1.3：基础命令认全了，但里面藏着几个一旦敲错就无法撤销的危险动作（比如 `rm -rf`）。下一课 **1.3《危险命令识别表》**，把 8 类必须拦住的高危命令做成手边速查表。

## 录制注意事项

- 录屏前把终端提示符精简成只显示目录名或虚拟用户名（不要露出个人电脑真名或公司内网主机名）。
- 如果使用 Mac 录屏，务必在口播和字幕里同时带出 Windows PowerShell 的打开方式和对应写法（`python` vs `python3`、`dir` vs `ls`）。
