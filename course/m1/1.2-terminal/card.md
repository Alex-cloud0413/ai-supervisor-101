## 第 2 张：别怕黑窗口，它和文件夹管的是同一台电脑

**页眉标签**：01｜拆解命令

你平时靠鼠标双击（GUI），AI 没有鼠标，它通过**终端（Terminal）**敲字干活（CLI）——Mac 搜「终端」，Windows 搜「PowerShell / 终端」。

终端里每条命令都长这 3 段：

**`动词`（干什么） + `参数`（怎么干，常带 `-`） + `路径`（动哪儿）**

比如 `ls -la sales`：列出（`ls`）包括隐藏文件在内的详细清单（`-la`），目标是 `sales` 文件夹。

## 第 3 张：看文件、走目录的 7 个基础命令

**页眉标签**：02｜日常导航

在 AI 的轨迹里最常出现的 7 个词（Mac 终端和 Windows PowerShell 基本通用）：

- **`pwd`**：我现在在哪？（迷路先敲它）
- **`ls`**（老 CMD 叫 `dir`）：当前文件夹里有什么？`ls -a` 可看隐藏文件
- **`cd <路径>`**：切换文件夹（`cd ..` 退上一级；敲完不会弹窗口，只改当前位置）
- **`mkdir <目录名>`**：新建文件夹
- **`cat <文件>`**：在屏幕直接看文本内容
- **`cp` / `mv`**：复制文件 / 移动或改名
- **`clear`**：清屏（只清显示，**绝不删文件**）

## 第 4 张：装工具、跑脚本必见的 5 个命令（分清两对兄弟）

**页眉标签**：03｜引擎与商店

零基础看教程最晕的 5 个词，拆成两个阵营就秒懂：

**Python 阵营（处理表格、数据自动化）**
- **`python` / `python3`**：运行 `.py` 脚本（Mac 常用 `python3`，Windows 常用 `python`）。
- **`pip`**：Python 的应用商店，用来装扩展包（如 `pip install openpyxl` 装读写 Excel 的工具）。

**Node.js 阵营（启动现代 AI 工具）**
- **`node`**：Node.js 运行环境（`node -v` 查版本）。
- **`npm`**：Node.js 的应用商店，用来装包。
- **`npx`**：**「免安装即跑」启动器**——不用先全局安装，一行 `npx @deepseek-ai/dsh web` 直接拉起工具。

## 第 5 张：看懂终端输出，别被 `warn` 吓住

**页眉标签**：04｜排错心态

新手敲完命令，屏幕刷出一堆英文先别慌，盯住两个关键词就够了：

- **看到 `warn`（如 `npm warn`）**：只是温馨提醒，**不是报错**，程序照常往下跑。
- **看到 `Error` 或 `command not found`**：才是真的卡住了——通常说明对应软件（比如 Node.js 或 Python）还没装，或者还没重启终端生效。

还有 `rm`（删除）这个动词，下一课 1.3 单独拿出来做危险命令红灯表。
