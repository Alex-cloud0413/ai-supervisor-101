# 4.1 录播参考脚本：Git = 游戏存档

> 建议时长：9–11 分钟（边操作边录，此脚本只作参考，不逐字照念）
> 演示材料：把 `practice/` + `.gitignore` 复制到一份独立的临时练习目录，终端全程开大字号。

---

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| `Git` | 吉特 | 装在你自己电脑上的「游戏存档机」，断网也能用 |
| `commit` | 科米特 | 正式按下「保存进度」打出来的一笔历史存档 |
| `status` | 斯泰特斯 | 查当前文件夹有哪些文件改了、还没存档 |
| `restore` | 瑞斯托尔 | 把没存档的改坏文件一键还原成上一档 |
| `revert` | 瑞沃特 | 对已经存进去的错档做一次安全反悔（新增一条抵消记录） |
| `HEAD` | 海德 | 指向你当前最新那一笔存档的小箭头 |

## 分段参考

| 时间 | 屏幕画面 | 口播要点 |
|---|---|---|
| 00:00–01:20 | 打开一个摆满 `v1`、`v2_终版`、`终版_别删` 的杂乱文件夹示意图 | 痛点共鸣：靠复制改名防翻车，碰上 AI 一轮改 3 个文件立刻失效。引出「打 Boss 前先存档」——这就是 Git。 |
| 01:20–02:30 | 展示系统位置图 + `git --version` 实机输出 | 先把最大误区拆开：**Git 在本地电脑，GitHub 在云端网站**，前 3 课先用熟本地存档机。顺带一句交代 Mac / Windows 怎么确认装好了 Git。 |
| 02:30–05:00 | 在沙盒 `ai-radar` 里敲 `git init -b main` → `git status -s` → `git add .` → `git commit -m "..."` | 慢动作讲清 5 个命令，重点解释为什么 `add`（挑货装箱）和 `commit`（封箱贴单）分两步；指着输出里的 10 个文件点出 `.gitignore` 自动挡掉了 `.env` 和 `output/`。 |
| 05:00–07:20 | 故意把 `config.yaml` 改乱 → 敲 `git status -s` 看到 `M` → 敲 `git restore config.yaml` 瞬间恢复 | **现场爽感高潮**：3 秒读档无痛复原！紧接着演练「已经 commit 了怎么反悔」：跑 `git revert HEAD --no-edit`，展示 `git log --oneline` 里干净留痕。 |
| 07:20–08:30 | 高亮对比 `restore` / `revert` 与红灯命令 `git reset --hard` | **破误解停顿**：① Git 不会自动存草稿，大改前必须先 commit；② 见到 AI 提议 `git reset --hard` 立刻按 1.3 课红线拦截。 |
| 08:30–09:40 | 切到第 5 节 3 个职场瞬间 | 停顿 5 秒让学员心里选命令，再揭晓答案（`status` / `restore` / 拒 `reset --hard` 用 `revert`）。 |
| 09:40–10:15 | 预告下一课 4.2《读懂 diff》 | 收尾：存档前怎么花 15 秒确认 AI 到底改对了没有？下节看 `git diff`。 |

## 录制注意事项

- 录制前先检查终端里 `git config user.name` 和 `user.email`，改成演示用的脱敏名称（如 `ai-radar-demo` / `demo@example.com`），避免录进作者真实私人邮箱。
- 在独立副本目录演示 `git init`，不要在真实课程仓库根目录重跑 `git init`。
- 敲 `git revert` 时加上 `--no-edit` 参数，避免终端突然弹出 Vim/Nano 编辑器卡住零基础观众节奏。
