## 第 2 张：先分清一件事：Git 和 GitHub 不是一回事

**页眉标签**：01｜别再混为一谈

- **Git**：装在你自己电脑里的存档工具，负责保存每次改动（commit）、看差异（diff）、切分支。断网也能用。
- **GitHub**：架在网上的托管与协作网站，把 Git 仓库放上云端，提供网页浏览、版本发布、报 Bug 和多人审核。

GitHub 既能建 **Public（公开）** 仓库，也能建 **Private（私有）** 仓库。公司业务资料记得建私有。

---

## 第 3 张：右上角 3 个按钮，新手最容易点错 Fork

**页眉标签**：02｜顶栏与按钮

打开仓库先看斜杠前后：`deepseek-ai / deepseek-harness`（谁发的 / 仓库名）。

右上角 3 个按钮别乱点：

- **Star**：收藏 + 点赞，用来衡量关注度。
- **Watch / Notifications**：订阅动态通知。
- **Fork**：把仓库复制到**你自己的 GitHub 云端账号**下。想下载到电脑试用，不要点 Fork——下载源码点绿色 `<> Code`，下载安装包去右侧 `Releases`。

## 第 4 张：顶部 7 个标签页，各自管什么？

**页眉标签**：03｜功能分区

仓库管理员可以按需开关标签（比如 DeepSeek Harness 关了 Issues，改用 Discussions；OpenAI Codex 7 个全开）：

- **Code**：文件列表和说明书主页
- **Issues**：报 Bug 和提需求——遇到报错先来这搜
- **Discussions**：论坛问答区（关掉 Issues 的项目在这里报 Bug）
- **Pull requests（PR）**：改动审核申请，看自动检查通没通过
- **Actions**：自动跑测试的流水线（绿勾通过、红叉失败）
- **Security / Insights**：安全公告 & 项目活跃度统计

## 第 5 张：不用看源码，先认准这 4 个根目录文件

**页眉标签**：04｜必看文件

打开任何开源项目，盯住这 4 个就够了：

1. **`README.md`**：项目说明书，怎么安装、怎么用直接写在这里。
2. **`LICENSE`**：开源许可证。点开看顶部绿勾红叉摘要——比如 MIT 明确标着「可商用 ✓、不担责 ✗」。
3. **`.gitignore`**：不上传清单，用来拦住 `.env` 密钥和临时缓存，防止误传上网。
4. **`AGENTS.md`**：写给 AI 看的项目规则书，越来越多新项目都会配。

## 第 6 张：1 分钟摸清一个开源项目的固定动线

**页眉标签**：05｜查项目顺序

下次老板或同事甩来一个 GitHub 链接，按这 5 步直接查：

1. 看顶栏：确认是不是官方账号 + 最近提交时间；
2. 滚到底部读 **README**：看清用途和安装命令；
3. 点 **LICENSE**：确认能不能免费商用；
4. 点右侧 **Releases**：看最新版本号（注意有没有 `Pre-release` 预览标）和更新日志；
5. 遇报错去 **Issues / Discussions** 搜关键词。
