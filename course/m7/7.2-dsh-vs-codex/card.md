## 内容卡 01

- **页眉标签**：01｜5 维对比一眼看清差异
- **正文**：
  - **网络门槛**：DSH 接 DeepSeek API 国内直连；Codex 需海外网络
  - **模型自由度**：DSH 通吃几十家模型按性价比切换；Codex 深度调优 OpenAI 生态
  - **计费方式**：DSH 纯 API 按量付费；Codex 含 ChatGPT 免费/Go/Plus/Pro 套餐与 API 双轨
  - **特色场景**：DSH 强在 MIT 开源透明 + 本地定时表单；Codex 强在桌面工作台 + 云端异步提 PR

---

## 内容卡 02

- **页眉标签**：02｜怎么算账最省钱？（别盲目包月！）
- **正文**：
  - **每周只跑 2–3 次轻度任务**：选 DSH + 低价按量 API（DeepSeek / Gemini Flash），月花往往不到一杯奶茶钱
  - **每天连续重度改代码几小时**：选 ChatGPT 订阅套餐内含的 Codex 额度更稳、不怕按量飙账单
  - 记住：不管哪家 API，都要先设好**消费硬上限**！

## 内容卡 03

- **页眉标签**：03｜3 套直接照抄的职场搭配
