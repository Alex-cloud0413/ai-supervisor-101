## 内容卡 01

- **页眉标签**：01｜DSH 自动化任务：5 项像定闹钟一样配完
- **正文**：
  - 入口：左侧栏 **「自动化任务」→「新建自动化任务」**（表单手动创建不花额度）
  - **名称 + 指令**：写清跑哪份脚本、汇报什么、绝不碰 `data/` 原文件
  - **执行位置**：日报类推荐选「每次新建对话」，干净且省 Token
  - **关联工作区**：必选项目目录（如 `ai-radar`），自动带上 `AGENTS.md`
  - **时间与时区**：选「周一至周五 08:30」+「中国标准时间」
  - 小技巧：建完点 **`...` →「立即执行」**，当场试跑验收！

---

## 内容卡 02

- **页眉标签**：02｜必须知道的 2 条真实边界（别踩坑！）
- **正文**：
  - **边界 ① 关机/关软件会暂停**：DSH 是本机宿主，笔记本合盖休眠后不会在云端继续跑
  - **边界 ② 每次唤醒都在花 API 额度**：
    - 绝不手滑设成「每 1 分钟 / 每 5 分钟」
    - 无人值守任务严禁写「自动删文件 / 自动群发消息」

---

## 内容卡 03

- **页眉标签**：03｜一张表选对你的 3 种定时方案
- **正文**：
  - **需要 AI 动脑总结 + 电脑白天常开** → **DSH「自动化任务」**（零代码最快）
  - **纯跑固定 Python 脚本 + 想零 Token 成本** → **Mac `launchd` / Windows 任务计划程序**
  - **电脑关机也要 24 小时稳定跑** → **GitHub Actions 云端 `schedule`**
  - 提示：GitHub Actions 的 `cron` 用 **UTC 时区**，北京时间 8:30 要减 8 小时写成 `"30 0 * * 1-5"`！
