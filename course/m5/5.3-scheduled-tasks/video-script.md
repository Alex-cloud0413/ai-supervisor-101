# 5.3 录播参考脚本：让 AI 自动按时干活

> 建议时长：9–11 分钟（边操作边录，此脚本只作参考，不逐字照念）
> 演示材料：DeepSeek Harness 网页版 `0.2.2-rc.5`（已关联 `ai-radar` 工作区），打开左侧栏「自动化任务」页面。

---

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| `Schedule` | 斯凯朱尔 | 定时调度，给 AI 定一个按点响起的自动任务闹钟 |
| `cron` | 克朗 | 电脑世界通用的 5 位定时时间表达式（分 时 日 月 周） |
| `UTC` | 优踢西 | 世界协调时间，北京时间（UTC+8）比它快 8 小时 |
| `Token` | 托肯 | 大模型按字数计费的计量单位，每次唤醒 AI 都会消耗 |
| `GitHub Actions` | 吉特哈布 艾克申斯 | GitHub 自带的云端自动执行流水线，关了电脑也能跑 |

| 时间 | 屏幕画面 | 口播要点 |

## 录制注意事项

- 录完「立即执行」演示后，记得顺手把测试用的定时任务点「暂停」或「删除」，避免自己电脑以后每天定时白扣 API 费用。
- 讲解 `cron: "30 0 * * 1-5"` 时，用手指着 `30`（分）和 `0`（UTC 0 点 = 北京时间早上 8 点）慢慢读一遍，避免观众搞反小时和分钟的顺序。
