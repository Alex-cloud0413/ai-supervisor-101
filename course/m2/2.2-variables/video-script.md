# 2.2 录播参考脚本：变量：给数据贴标签

> 建议时长：7–9 分钟（边展示 `build_top10.py` 顶部配置区边做小改动演示，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Variable | 中文直接说「变量」 | 贴了名字标签的数据收纳盒 |
| `str`（string） | 中文说「字符串」 | 带引号的纯文字 |
| `int` / `float` | 整数 / 浮点数（小数） | 不带引号、能做加减乘除的数字 |
| `bool`（boolean） | 布尔值 | 只有 `True` 和 `False` 的真假开关 |
| `None` | 难（读作「空值」） | 表示压根没填数据 |
| `float()` | 弗洛特 | 把带引号的数字文字转成真小数的工具 |

## 0:00 – 0:45｜开场 Hook（3 秒看懂一次改需求的 Diff）

- **屏幕画面**：直接亮出 4 行红绿 Diff：`- EXCHANGE_RATE = 7.2` → `+ EXCHANGE_RATE = 7.3`，`- TOP_N = 10` → `+ TOP_N = 20`。
- **口播要点**：
  - 「老板临时说汇率按 7.3 算、多拉 10 个模型，AI 改完给你弹出 Diff。不用看底下 140 行，只看顶上这 4 行，3 秒就能确认改对了没有。」
  - 引出主题：这叫「变量」，就是整份脚本的仪表盘。

## 0:45 – 2:30｜赋值 `=` 和全大写配置区

- **屏幕画面**：打开 `practice/scripts/build_top10.py` 第 16–21 行，圈出 `DATA_PATH`、`OUTPUT_PATH`、`EXCHANGE_RATE`、`TOP_N`。
- **口播要点**：
  - 用「贴标签的盒子」讲清楚 `=` 是「把右边放进左边」，顺手破一下 `count = count + 1` 的数学直觉误解，预告「问相不相等要用 `==`」。
  - 告诉观众一个实用暗号：脚本顶上全大写的变量就是专门留给你调参数的仪表盘。

## 2:30 – 5:00｜4 种数据类型 + OpenRouter「伪数字」真实大坑

- **屏幕画面**：并列展示 4 种类型示例，然后切到 `openrouter-models-2026-11-24.json` 里的 `"prompt": "0.00000004"`，现场在终端跑一行 `"0.00000004" * 7.2`，让屏幕吐出 `TypeError`。
- **口播要点**：
  - **关键停顿**：「看见没有？OpenRouter 给的价格两边带着双引号！它是文字，不是数字，直接乘 7.2 立刻翻车。」
  - 切回 `build_top10.py` 第 72 行指着 `float(pricing["prompt"]) * 1_000_000`：解释 `float()` 就是撕掉引号转小数，`1_000_000` 里的下划线只是方便人眼数零。
  - 顺带提醒一句：`True` / `False` 千万别加引号，加了引号就变成普通文字了。

## 5:00 – 7:15｜现场找错练习 + 下集预告

- **屏幕画面**：贴出第 5 节的 8 行 Diff（里面藏了 `EXCHANGE_RATE = "7.3"` 和 `OUTPUT_PATH = BASE_DIR / "data" / ...`），停 5 秒让观众挑刺。
- **口播要点**：
  - 揭晓两个坑：一个多加了引号会算崩，一个把产物写进了原始 `data/` 目录。
  - 预告 2.3：今天看懂了单个盒子，下节课把 470 个模型打包在一起看——**2.3《列表与字典：数据长什么样》**。

## 录制注意事项

- 终端现场演示 `"0.00000004" * 7.2` 触发 `TypeError` 时，顺手演示 `float("0.00000004") * 1_000_000 * 7.2` 得出 `0.288`，让观众直观看到数字和文字的差别。
