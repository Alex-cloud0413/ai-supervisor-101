## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Function | 坊克申（中文说「函数」） | 把一段固定操作打包起名形成的功能部门 |
| `def` | 戴夫（define 缩写） | 宣告「这里开始定义一个函数」 |
| Parameter / Argument | 中文直接说「参数」 | 括号里递给函数加工的原材料 |
| `return` | 瑞腾（返回） | 把加工好的成品真正交回给下一步代码 |
| `main()` | 梅恩（主入口） | 串联各个部门的总调度函数 |

## 0:50 – 3:30｜函数的 3 个零件 + `print` vs `return` 大坑

- **屏幕画面**：放大 `load_models`（5 行），用色块标出「门牌与参数」「缩进加工体」「`return` 交成品」。然后并列演示「写 `print` 忘写 `return`」导致下一个变量接到 `None`。
- **口播要点**：
  - **重点破误解**：`print` 只是把字打印到屏幕上给你眼睛看，就像厨师喊了一嗓子「菜炒好了」但没端出来；`return` 才是真正把盘子端给下一道工序。
  - 顺带解释文件最底下的 `if __name__ == "__main__": main()`——把它记住成「总开关」，读陌生脚本**第一眼先拉到最底下看 `main()`**。
