# 2.4 录播参考脚本：`if`：什么情况做什么事

> 建议时长：9–11 分钟（边对照 `lyria-3` 真实 JSON 和 `build_top10.py` 的 4 道 `if` 门边讲，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| `if` / `elif` / `else` | 如果 / 否则如果 / 其余情况 | 分支条件判断关键词 |
| `==` / `!=` | 等于 / 不等于 | 比较两边是否相等（注意判断相等是两个等号） |
| `in` / `not in` | 在里面 / 不在里面 | 检查某段文字或元素有没有包含在目标里 |
| `and` / `or` / `not` | 并且 / 或者 / 不是 | 把多个条件拼在一起的逻辑词 |
| `Indentation` | 中文直接说「缩进」 | 每行左边退的 4 个空格，决定哪些行归上面的 `if` 管 |

## 0:00 – 1:00｜开场 Hook（揭开 0.1 课 `lyria-3` 的真相）

- **屏幕画面**：直接放大展示 `google/lyria-3-pro-preview` 的真实 JSON，红圈标出 `"output_modalities": ["text", "audio"]`。
- **口播要点**：
  - 「0.1 课里谷歌的音乐生成模型混进了文字榜，你以为写一句 `if "text" not in outputs` 就能拦住它？看它真实 JSON——里面偏偏写着 `["text", "audio"]`！包含 `text`，但还带 `audio`，写宽一点照样放行。」
  - 点题：M2 里含金量最高的一课——业务口径 90% 都在 `if` 里，学会扫 `if` 就能一眼揪出逻辑漏洞。

## 1:00 – 3:30｜`if` 缩进规则 + 6 个必认判断符号

- **屏幕画面**：展示 `if / elif / else` 分档例子，用竖线标出 4 个空格的缩进对齐；接着亮出 6 个判断符号对照表。
- **口播要点**：
  - 强调两件事：末尾冒号 `:` 和左侧 4 个空格（Python 靠缩进认归属，退错格逻辑就跑偏）。
  - 再次敲黑板区分单个 `=`（装进去）和双等号 `==`（问相不相等）。

## 3:30 – 5:30｜重点攻克监工头号大坑：`and` vs `or`

- **屏幕画面**：上下并列贴出两句只差一个词的代码：
  - `if prompt_usd <= 0 or completion_usd <= 0: return False`
  - `if prompt_usd <= 0 and completion_usd <= 0: return False`
  右边贴出真实数据里的 `scaledown/summarize`（输入 `0.04`，输出 `0`）。
- **口播要点**：
  - **关键停顿**：「就差一个词！写成 `and`，必须输入输出同时为 0 才拦，`scaledown/summarize` 这种输出标 0 的工具立刻漏网；写成 `or`，任意一边 `<= 0` 就挡掉。以后在 Diff 里看见 `if` 带 `and` 或 `or`，一定要默念一遍中文！」
