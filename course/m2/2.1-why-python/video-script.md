# 2.1 录播参考脚本：为什么 AI 爱用 Python

> 建议时长：7–9 分钟（边展示 `build_top10.py` 边运行终端，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Python | 派森 | AI 最常用的脚本编程语言 |
| `.py` | 点 P-Y | Python 脚本文件的扩展名 |
| Interpreter | 中文直接说「解释器」 | 电脑里负责读懂 `.py` 文件并按步骤执行的程序 |
| `import` | 音泡特（导入） | 从工具箱里借用某个功能库 |
| `def` | 戴夫（define 的缩写） | 定义一个打包好的功能块（函数） |
| `print` | 普林特（打印） | 把文字或结果输出到终端屏幕上给你看 |

## 0:00 – 0:50｜开场 Hook（先回答职场人最真实的疑问）

- **屏幕画面**：左半屏打开 `data/openrouter-models-2026-11-24.json`（密密麻麻的 470 条 JSON），右半屏放 `practice/scripts/build_top10.py` 和生成的 `模型比价Top10.xlsx`。
- **口播要点**：
  - 直接切痛点：「很多人问我：我用 Excel 拉拉筛选也能比价，AI 干嘛老爱在文件夹里留一堆 `.py` 文件？」
  - 算时间账：470 条嵌套 JSON、4 道过滤口径、下周换新快照还要重跑——手工在 Excel 里粘一次 20 分钟还容易漏，一份 `.py` 脚本 1 秒跑完，每次口径一字不差。
  - 给观众定调：M2 整个模块一共 8 课，**不要求你背语法写代码，只教你用「监工体检法」读懂 AI 写的 Python**。

## 0:50 – 2:30｜系统位置：图纸（`.py`）和施工队（`python3`）

- **屏幕画面**：展示「你提需求 → 模型写 `.py` 图纸 → Harness 敲 `python3 脚本名.py` → 解释器读写硬盘 → 输出结果」的流程。
- **口播要点**：
  - **破误解**：用普通记事本或文本编辑双击打开 `build_top10.py`，让观众亲眼看到 `.py` 就是纯文本，不是什么神秘黑盒程序。
  - 点清 AI 最爱 Python 的 3 个原因：像英语好读、免费库齐全（`json` / `openpyxl` / `pandas`）、模型训练素材最多所以写得最稳。

## 2:30 – 5:30｜现场拆骨架 + 终端跑一遍

- **屏幕画面**：打开 `practice/scripts/build_top10.py`，按从上到下用鼠标圈出 4 块区域：顶部 `import` → 顶部配置变量（`EXCHANGE_RATE = 7.2`、`TOP_N = 10`）→ 中间 5 个 `def` → 底部 `main()`。
- **口播要点**：
  - 强调「先看 4 段骨架，千万别从第 1 行死磕到最后一行」。
  - 切到终端（顺带口头提示 Mac 用 `python3`、Windows 用 `python`），现场敲 `python3 practice/scripts/build_top10.py`，看着 1 秒吐出 470 个模型筛出的 Top 5，再点开生成的 `output/模型比价Top10.xlsx` 验证结果。

## 5:30 – 7:30｜互动练习 + 下集预告

- **口播要点**：
  - 带观众指认 `"r"`（只读）和 `print`（只打印不改文件），强化「看懂就能放心放行」的信心。
  - 预告 2.2：下一课从骨架里监工改得最勤的那一块拆起——**2.2《变量：给数据贴标签》**，3 秒看懂 AI 在 Diff 里改了哪个参数。
