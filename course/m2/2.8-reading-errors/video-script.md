# 2.8 录播参考脚本：读懂报错

> 建议时长：8–10 分钟（边现场在终端故意触发 3 个经典小错、边演示「倒着读」给 AI 发三件套，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| Traceback | 追斯贝克（报错堆栈） | Python 报错时打印的「从入口到出事点」的完整追踪单 |
| `FileNotFoundError` | 找不到文件错误 | 路径不对、文件名写错或没 `cd` 进目录 |
| `ModuleNotFoundError` | 找不到模块错误 | 缺第三方库，还没跑 `pip install` |
| `KeyError` | 键错误 | 字典里找不到这个字段名 |
| `TypeError` / `ValueError` | 类型错误 / 值错误 | 把文字当数字算，或拿 `'N/A'` 转小数失败 |
| `SyntaxError` / `IndentationError` | 语法错误 / 缩进错误 | 漏冒号、用了中文引号、或左侧空格没对齐 |

## 0:00 – 0:50｜开场 Hook（先给观众祛魅：报错绝不等于弄坏电脑）

- **屏幕画面**：屏幕上直接甩出一段 10 行的 `Traceback` 英文红字。
- **口播要点**：
  - 先安抚情绪：「每次屏幕哗啦啦吐出一大片英文红字，新手第一反应都是慌——是不是电脑被我弄坏了？先吃定心丸：普通 Python 报错只是当前脚本停机，绝对不会伤系统，也不会删你硬盘数据。」
  - 点出最差和最好的两种做法：只给 AI 发一句「报错了帮我修」，AI 会瞎猜越改越乱；学会今天这招「倒着读」，10 秒抓准病因，一次指挥到位。

## 0:50 – 3:00｜核心招式：「从最后一行往上读」三步法

- **屏幕画面**：在 10 行 Traceback 上从底往上画 3 个箭头：① 最后一行（病名 + 病因）→ ② 往上找属于自己脚本的 `File "...", line XX`（跳过第三方库路径）→ ③ 打包成「报错三件套」交给 AI。
- **口播要点**：
  - **关键停顿**：重点讲第三步那句「监工护身符」——「让 AI 修错时，顺嘴补一句『先说明根因再改，不要用 try/except 静默填 0 把报错盖住』，能直接拦住 0.1 课讲过的那种偷懒假修复。」

## 3:00 – 6:30｜实测过一遍 5 类高频报错（重点演示 3 个现场触发）

- **屏幕画面**：亮出 5 类高频报错速查表，接着切到终端依次触发并倒着拆解 3 个真实 `ai-radar` 报错：
  1. `FileNotFoundError`（文件名写错成 `11-25.json`）；
  2. `KeyError: 'input'`（把 `"prompt"` 猜成 `"input"`，指出 Python 3.12 贴心的 `~~~~~~~^^^^^^^^^` 指示符）；
  3. `TypeError: can't multiply sequence by non-int of type 'float'`（忘了 `float()` 拿价格字符串直接乘 `7.2`）。
- **口播要点**：
  - 每条都带着观众把 M2 前几课串起来：看到 `KeyError` 想到 2.3 字典键名，看到 `TypeError` 想到 2.2 引号和 `float()`，看到 `ModuleNotFoundError` 想到 2.7 `pip install`，看到 `IndentationError` 想到 2.4 缩进 4 格。

## 6:30 – 8:30｜综合实战演练 + M2 结业收尾

- **屏幕画面**：贴出第 5 节的 10 行 `ValueError: could not convert string to float: 'N/A'` 完整堆栈，留 5 秒让观众说出「第几行、什么错、怎么发给 AI」，再揭晓答案。
- **口播要点**：
  - 祝贺 M2 全模块 8 课通关：现在拿到 AI 写的几百行 Python 脚本和满屏报错，你都已经能从容验收、指挥精准。
  - 预告 M3：下一课把视角从单个脚本拉高到整套工程——**3.1《项目文件夹的标准结构》**，看清 README、脚本、原始快照、配置文件和输出目录各归各位。
