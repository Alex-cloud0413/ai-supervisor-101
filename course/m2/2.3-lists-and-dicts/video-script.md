# 2.3 录播参考脚本：列表与字典：数据长什么样

> 建议时长：8–10 分钟（边对照真实 JSON 文件和 `build_top10.py` 取值代码边讲，以下为口播要点与屏幕节点，不作逐字稿）。

## 中英术语读法

| 术语 | 读法 | 首次出现时的口头解释 |
|---|---|---|
| List | 利斯特（中文说「列表」） | 方括号 `[]` 包起来的有序队伍 |
| Dict（Dictionary） | 迪克特（中文说「字典」） | 花括号 `{}` 包起来的「字段名: 值」卡片 |
| Key / Value | 键 / 值 | 字典里冒号左边叫键（字段名），右边叫值（具体内容） |
| Index | 中文说「索引」或「编号」 | 列表里每个元素排第几号，从 0 开始数 |
| `.get()` | 点 get | 字典的安全取值方式，找不到字段不崩溃 |
| `len()` | 楞（length 的缩写） | 数一数列表里一共有多少条 |

## 0:45 – 3:00｜列表 `[]`：重点叮嘱「从 0 开始数」

- **屏幕画面**：展示 `inputs = ["text", "image", "video"]` 和 `top_models[:10]`，在每个元素底下标上 `0`、`1`、`2`。
- **口播要点**：
  - 重点停顿强调：**Python 从 0 开始数**。`top_models[0]` 才是第 1 名，`top_models[1]` 是第 2 名；`[:10]` 是取前 10 个，`len(models)` 是查总数 470。
